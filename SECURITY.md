# Security

Please do not post API keys, OAuth tokens, private screenshots, or exploitable security details in a public issue.

Use GitHub’s private vulnerability reporting feature on this repository for security reports. Include the affected version, reproduction steps, impact, and any suggested mitigation.

Stickman is a local desktop prototype with optional access to screenshots, Accessibility, Calendar, Reminders, microphone input, browser automation, and third-party services. Each capability should remain independently permissioned, and external content must never silently authorize a local or remote action.
